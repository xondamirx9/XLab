# Аудит: чего не хватает и что лишнее

> [!summary] Коротко
> Техническая основа крепкая: заявки не теряются, лимиты и заголовки безопасности на месте, 63 теста проходят.
> Слабое место — **продажа**: на сайте нет контактов, почти нет кейсов и отзывов, а главная «фишка» (бесплатный ИИ-сайт за 15 минут в боте) на сайте вообще не упоминается.
> Второе слабое место — **управление**: один общий пароль на всё, заявки без статусов, бэкапы вручную, нет CI и мониторинга.
> Лишнее — в основном код: админка и генератор страницы отдаются каждому посетителю, разметка и цены продублированы.

## Что сделано хорошо — не сломать

- [x] Заявка сначала пишется в базу, потом пересылается; повтор раз в минуту, до 30 попыток (`app/bot.py`).
- [x] Повторная отправка не создаёт дубль (`client_id` UNIQUE).
- [x] Лимиты: 5 заявок за 10 минут с адреса, 120 в час со всех адресов, 5 неверных паролей → пауза 15 минут, IPv6 считается по /64.
- [x] `X-Forwarded-For` читается только от прокси на этой же машине и берётся последний адрес.
- [x] Пароль сравнивается без утечки по времени (`hmac.compare_digest`).
- [x] Атомарная запись сайта и 20 резервных копий.
- [x] В журнал не пишутся имена и телефоны.
- [x] Сайты клиентов: только экранированный текст, единственный скрипт разрешён по хешу в CSP, агенты отдают данные, а не код.
- [x] Уроки из проектов клиентов действуют только после одобрения админом (защита от prompt injection через уроки).
- [x] Контакты клиента не попадают в промпты агентов (`app/studio/pipeline.py:104`).
- [x] Токен страницы проекта — 128 бит (`secrets.token_urlsafe(16)`).
- [x] systemd: `ProtectSystem=strict`, `NoNewPrivileges`, запись только в `data/` и `site/`.
- [x] Офлайн-режим студии: без ключа Claude всё работает.
